Installation

Add the SDK to your Maven project:

<dependency>
    <groupId>com.sirv</groupId>
    <artifactId>sirv-rest-api-java</artifactId>
    <version>1.0.0</version>
</dependency>

Or for Gradle:

implementation 'com.sirv:sirv-rest-api-java:1.0.0'

Requirements

  • Java 11 or higher
  • OkHttp 4.x
  • Gson 2.x

Quick Start

import com.sirv.api.client.SirvClient;
import com.sirv.api.model.*;

// Initialize and connect
try (SirvClient client = new SirvClient("your-client-id", "your-client-secret")) {
    client.connect();

    // Get account information
    AccountInfo account = client.getAccountInfo();
    System.out.println("Account: " + account.getAlias());

    // List files in a directory
    FolderContents contents = client.readFolderContents("/");
    for (FileInfo file : contents.getContents()) {
        System.out.println(file.getFilename());
    }
}

Authentication

The SDK handles authentication automatically when you call connect(). It obtains an access token using your client credentials and automatically refreshes it when needed.

Note: Get your API credentials from the Sirv Dashboard. 
SirvClient client = new SirvClient("your-client-id", "your-client-secret");

// Connect with default token expiry (1200 seconds)
client.connect();

// Or connect with custom expiry (5-604800 seconds)
client.connect(3600); // Token valid for 1 hour

// Get token information
TokenResponse token = client.getToken();
System.out.println("Expires in: " + token.getExpiresIn() + " seconds");
System.out.println("Scopes: " + token.getScope());

Token Expiry Options

Duration Seconds Use Case
Minimum 5 Very short-lived operations
Default 1200 (20 min) Standard API operations
1 Hour 3600 Batch processing
Maximum 604800 (7 days) Long-running processes

Upload Files

// Upload from bytes
byte[] content = "Hello, World!".getBytes(StandardCharsets.UTF_8);
client.uploadFile("/documents/hello.txt", content, "text/plain");

// Upload from local file
Path localFile = Path.of("./photo.jpg");
client.uploadFile("/images/photo.jpg", localFile);

Download Files

// Download to bytes
byte[] content = client.downloadFile("/images/photo.jpg");

// Download to local file
Path destination = Path.of("./downloads/photo.jpg");
client.downloadFileTo("/images/photo.jpg", destination);

Copy, Rename, Delete

// Copy file
client.copyFile("/images/photo.jpg", "/backup/photo.jpg");

// Rename/move file
client.renameFile("/images/old-name.jpg", "/images/new-name.jpg");

// Delete file
client.deleteFile("/images/old-photo.jpg");

Metadata Operations

// Get and set file metadata
FileMeta meta = new FileMeta();
meta.setTitle("Beautiful Sunset");

Batch Operations

// Create ZIP archive
List<String> files = Arrays.asList(
    "/images/photo1.jpg",
    "/images/photo2.jpg"
);

BatchResult result = client.batchZip(files, "/archives/photos.zip");
System.out.println("Job ID: " + result.getJobId());

// Check ZIP status
BatchResult status = client.getZipStatus(result.getJobId());
if ("completed".equals(status.getStatus())) {
    System.out.println("ZIP created: " + status.getFilename());
}

Search API

Search for files using Elasticsearch-style queries.

Basic Search

Map<String, Object> params = new HashMap<>();
params.put("query", "extension:jpg");
params.put("size", 100);

SearchResult results = client.searchFiles(params);
System.out.println("Found: " + results.getTotal() + " files");

for (Map<String, Object> hit : results.getHits()) {
    FileInfo info = SearchResult.extractFileInfo(hit);
    System.out.println("  - " + info.getFilename());
}

Advanced Queries

// Search multiple extensions
params.put("query", "extension:(jpg OR png OR gif)");

// Search by filename pattern
params.put("query", "basename:product*");

// Search by directory
params.put("query", "dirname:/images/2024");

// Search by size
params.put("query", "size:>1000000"); // Larger than 1MB

// Combined query
params.put("query", "extension:jpg AND size:>500000 AND dirname:/products");

Pagination with Scroll API

List<FileInfo> allFiles = new ArrayList<>();
SearchResult results = client.searchFiles(params);

// Add first page
for (Map<String, Object> hit : results.getHits()) {
    allFiles.add(SearchResult.extractFileInfo(hit));
}

// Continue scrolling
while (results.getScrollId() != null && !results.getHits().isEmpty()) {
    results = client.scrollSearch(results.getScrollId());

    for (Map<String, Object> hit : results.getHits()) {
        allFiles.add(SearchResult.extractFileInfo(hit));
    }
}

System.out.println("Total files: " + allFiles.size());

Account API

Manage your Sirv account settings and retrieve account information.

Available Methods

Method Description
getAccountInfo() Get account information including CDN URL and account name
updateAccountInfo(Map) Update account settings
getAccountLimits() Get API request limits and usage
getStorageInfo() Get current storage usage
getAccountUsers() List all account users
getBillingPlan() Get billing plan details

Examples

// Get account information
AccountInfo account = client.getAccountInfo();
System.out.println("CDN URL: " + account.getCdnUrl());
System.out.println("Alias: " + account.getAlias());

// Get storage information
StorageInfo storage = client.getStorageInfo();
System.out.println("Used: " + storage.getUsed() + " bytes");
System.out.println("Files: " + storage.getFiles());

// Get API limits
AccountLimits limits = client.getAccountLimits();
if (limits.getRest() != null) {
    System.out.println("Remaining: " + limits.getRest().get("remaining"));
}

Statistics API

Retrieve usage statistics for your account.

Method Description
getHttpStats(from, to) Get HTTP transfer statistics
getStorageStats(from, to) Get storage statistics
getSpinViewsStats(from, to) Get spin viewer statistics (max 5 days) 
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

LocalDate endDate = LocalDate.now();
LocalDate startDate = endDate.minusDays(30);

String from = startDate.format(DateTimeFormatter.ISO_DATE);
String to = endDate.format(DateTimeFormatter.ISO_DATE);

// HTTP transfer statistics
Map<String, Object> httpStats = client.getHttpStats(from, to);

long totalTransfer = 0;
for (Object value : httpStats.values()) {
    Map<String, Object> day = (Map<String, Object>) value;
    Map<String, Object> total = (Map<String, Object>) day.get("total");
    if (total != null) {
        Number size = (Number) total.get("size");
        if (size != null) totalTransfer += size.longValue();
    }
}
System.out.printf("Total transfer: %.2f GB%n", totalTransfer / 1e9);

// Storage statistics
Map<String, Object> storageStats = client.getStorageStats(from, to);

Points of Interest

// Get points of interest
List<PointOfInterest> pois = client.getPointsOfInterest("/spins/product.spin");

for (PointOfInterest poi : pois) {
    System.out.printf("%s: (%.2f, %.2f) frame %d%n",
        poi.getName(),
        poi.getX(),
        poi.getY(),
        poi.getFrame());
}

// Create a point of interest
PointOfInterest poi = new PointOfInterest();
poi.setName("feature-button");
poi.setX(0.5);   // X coordinate (0.0 to 1.0)
poi.setY(0.3);   // Y coordinate (0.0 to 1.0)
poi.setFrame(0); // Frame number

client.setPointOfInterest("/spins/product.spin", poi);

// Delete a point of interest
client.deletePointOfInterest("/spins/product.spin", "feature-button");

Error Handling

The SDK provides a custom exception type for API errors.

SirvApiException

Method Description
getMessage() Error message
getStatusCode() HTTP status code
getErrorCode() API error code (if available) 
import com.sirv.api.exception.SirvApiException;

try {
    client.uploadFile("/images/photo.jpg", content, "image/jpeg");
} catch (SirvApiException e) {
    switch (e.getStatusCode()) {
        case 401:
            System.out.println("Authentication failed");
            break;
        case 403:
            System.out.println("Permission denied");
            break;
        case 404:
            System.out.println("File not found");
            break;
        case 409:
            System.out.println("File already exists");
            break;
        case 429:
            System.out.println("Rate limit exceeded");
            break;
        default:
            System.out.println("Error: " + e.getMessage());
    }
}

Common HTTP Status Codes

Code Meaning
200Success
400Bad Request - Invalid parameters
401Unauthorized - Invalid or expired token
403Forbidden - Insufficient permissions
404Not Found - File or resource not found
409Conflict - File already exists
429Too Many Requests - Rate limit exceeded
500Internal Server Error

Try-With-Resources

The SirvClient implements AutoCloseable, so you can use try-with-resources for automatic cleanup:

try (SirvClient client = new SirvClient(clientId, clientSecret)) {
    client.connect();
    // ... use the client
} catch (SirvApiException e) {
    System.err.println("API Error: " + e.getMessage());
}
// Client is automatically closed
